# Customizable Report Card

A web app to generate customizable student report cards with interactive UI and real‑time inputs.

## 🔍 About

This project lets users create custom report cards by adding student details, grades, and performance comments. It’s built with modern frontend technologies and hosted live for easy access.

## 🚀 Live Demo

👉 https://customizable-report-card.vercel.app

## 🛠️ Features

- Add student information (name, subjects, marks)
- Generate a clean report card layout
- Customize performance remarks
- Responsive and user‑friendly UI

## 📦 Technologies Used

- **React** – For building UI components  
- **Vite** – Fast development tooling  
- **TypeScript** – Strongly typed JavaScript  
- **Tailwind CSS** – Utility‑first styling

## 📥 How to Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/JekenMaharjan/Customizable-Report-Card.git
   ```
   
2. **Go into the folder**
   ```bash
   cd client
   ```
   
3. **Install dependencies**
   ```bash
   npm install
   ```
   
4. **Start the project**
   ```bash
   npm run dev
   ```
